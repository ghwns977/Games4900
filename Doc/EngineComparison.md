1. They all have "Drag & Drop" workflow, which makes us easier to design the level. It is very intuitive. Also, all of them uses W/E/R key for Move, Rotate, and Scaling, which make me feel intuitive to control.
    Difference might be Coordinate. I saw that Unity and Godot is Y-up axis system, but Unreal was using Z-up axis, which makes unreal to have certain imported assets to be lying down.
    Also, after importing the files, Unity made .meta file to control file ID. While Unreal changed into .uasset file which is their own binary file. Godot was quite intuitive, they used .import file, which seems very light.
2. In a big scale, I can compare as Unity&Godot vs Unreal. Unity and Godot seems very similar that they have a concept of template like Prefab for Unity and Scene for Godot. But Godot was more interesting that everything was considered as a "Scene". But overall, comparing to Unreal, Unity and Godot gives a similar feeling to me.
Unreal was different, that even one object can be a "Class" that can build their own logic, which makes it really heavy. It has its own viewport for each blueprint and has own event graph.
3. Personally, I will choose Unity. It seems to be easiest for level prototyping and seems to be less heavy engine compared to Unreal. Yet, Godot seems to be the most light engine, but Unity's overall experience is way much intuitive for me.
